# Dragonbooru
A simple, local, offline gallery tagging, search, and organisation tool similar to e621.

This tool is built for large media libraries as a way to keep things organised.
Originally, it was just a personal tool to help me keep my media collection nice and organised,
however I saw that some people including artists could use this to organise and tag their portfolios.

This is the antithesis to current modern software. It is:
- Customiseable
- Fully FOSS
- Free of any machine learning integrations
- Offline
- Free of any age verification
- Free of any data collecting
- Free of any subscription service or fees
- Ad-free
- Easy to use and change to your liking
- Free of any data transmission

In a time where all software, no matter how insignificant, has some kind of data collection
and machine learning (or "AI" as corporations want you to call it) integrated into it
or is plagued by adverts, it relies on us as consumers to put the foot down and
say no to rampant uncontrolled corporate capitalism and surveillance states. I put my
money where my mouth is and made my own software because I did not like the current options
on the market. Hopefully many others will benefit from this software, especially artists.
